## Локальные модели LM Studio (быстрый старт)

Проверка: `curl http://127.0.0.1:1234/v1/models`; если пусто — `lms server start`.

Загрузка chat-модели (только так, дефолтная JIT-загрузка медленная):
```
lms load qwen/qwen3.5-9b --gpu max -c 4096 --parallel 1
```
Выгрузка: `lms unload qwen/qwen3.5-9b`. Статус: `lms ps`.

Правила (нарушение = генерация 9-26 ток/с вместо ~55):
- Не загружать embedding-модель в LM Studio вместе с LLM.
- Инстанс деградирует с возрастом — при замедлении выгрузить+загрузить.
- Первые 10-30 с после загрузки qwen3.5 «думает» — норма.
- **Запущенная игра = медленная LLM** (GPU общий): единицы ток/с во время игры —
  норма, не перезагружать. Контекст строго 4096: 8192 вызывает WDDM-вытеснение
  VRAM → 1-4 ток/с. Обрезания лечить компактнее промптом (меньше кусков в
  контексте), а не увеличением контекста.

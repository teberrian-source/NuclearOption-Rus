# Nuclear Option — русификатор (Russian Localization)

Словарь русского перевода и инструменты для **Nuclear Option 0.34.2**
(плагин `LocalizationPatch`, BepInEx 5.x).

- Плагин-основа: [9138noms/NuclearOption-LocalizationPatch](https://github.com/9138noms/NuclearOption-LocalizationPatch)
- Текущая версия словаря: **4256 записей** (`dict/ru.json`, 680 797 байт)
- Версия плагина в этом репозитории: **3.2.4** (`plugin/build/LocalizationPatch.dll`)

## Что переводится

| Переводим | Оставляем английским |
|---|---|
| Интерфейс, меню, настройки | Названия оружия и техники |
| Брифинги, описания миссий | Названия миссий и ливрей |
| Описания техники/оружия | Названия локаций (внутри фраз — тоже) |
| Подсказки, статусы HUD, названия задач | Деньги, дистанции, единицы, таймеры, координаты сетки |

Мусорные строки игры (`ConfigDescription.*`, placeholder-строки, Lorem ipsum) не переводятся.

## Установка

1. Установить BepInEx 5.x в папку игры, запустить игру один раз и выйти.
2. Скопировать в `<игра>/BepInEx/plugins/LocalizationPatch/`:
   - `plugin/build/LocalizationPatch.dll`
   - `dict/ru.json`
   - штатный `LocalizationPatchDropdown.dll` и шрифт `WDXLLubrifontSC-Regular.ttf`
     (из релизов базового плагина)
3. Запустить игру — перевод подхватится автоматически (язык определяется по `ru.json`).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+F5` | перезагрузить `ru.json` без перезапуска игры (старое `Ctrl+F10` тоже работает) |
| `Ctrl+F4` | выгрузить `extracted_gamedata.txt` (подсказки, энциклопедия) |
| `Ctrl+F6` | выгрузить `extracted_strings.txt` (длинные строки из памяти) |
| `F9` / `F10` | окно плагина со статистикой |

## Структура репозитория

```
dict/ru.json      словарь перевода
plugin/           исходники и сборка плагина (KoreanPatch/, csproj, build/, regex_test/)
tools/            скрипты раундов: сбор строк, слияние в ru.json, правки Plugin.cs
data/             рабочие выгрузки и пакеты перевода (untranslated, extracted, tr*.json, todo*.json)
PROJECT_STATE.md  состояние проекта: что сделано, как пересобрать, что осталось
```

## Сборка плагина

```powershell
cd plugin
dotnet build LocalizationPatch.csproj -c Release
```
Готовый файл: `plugin/bin/Release/LocalizationPatch.dll`. Игра при замене DLL должна быть закрыта.

## Известные проблемы

- При запуске игры возможны два подвеса по ~10 секунд: плагин сам выгружает определения
  (`ExtractGameData` + `ExtractAllStrings` — рефлексия по всем объектам игры). Лечится
  отключением авто-выгрузок, подробности — в `PROJECT_STATE.md`, §8.1.

# Nuclear Option — Russian Localization Patch v3.3.1

Плагин русификации интерфейса Nuclear Option (BepInEx 5.x, Unity 2022.3).

## Требования
- Nuclear Option (Steam, 0.34.x)
- BepInEx 5.x

## Установка
1. Установить BepInEx 5.x в папку игры.
2. Запустить игру один раз и выйти (BepInEx создаст папки).
3. Скопировать содержимое `BepInEx/plugins/LocalizationPatch/` в
   `<игра>/BepInEx/plugins/LocalizationPatch/`.
4. Запустить игру — перевод применяется автоматически.

## Файлы
- `LocalizationPatch.dll` — плагин перевода
- `LocalizationPatchDropdown.dll` — аддон для выпадающих списков/редактора
- `ru.json` — словарь русского перевода (4256 записей)
- `WDXLLubrifontSC-Regular.ttf` — шрифт с кириллицей

## Горячие клавиши
- `F9` / `F10` — показать/скрыть окно плагина (отладка, статистика). Доступно только при
  `ShowDebugWindow = true` в конфиге (в 3.3.1 по умолчанию выключено — окно не всплывает).
- `Ctrl+F5` — **перезагрузить `ru.json` без перезапуска игры** (правки словаря видны сразу;
  заменяет устаревшее `Ctrl+F10`)
- `Ctrl+F4` — выгрузить данные энциклопедии в `extracted_gamedata.txt` (устаревшее `Ctrl+F11`)
- `Ctrl+F6` — выгрузить все длинные строки из памяти игры в `extracted_strings.txt`
  (описания оружия/техники, включая модовые; устаревшее `Ctrl+F12`)

## Автовыгрузка (изменено в 3.3.0)
Раньше плагин **сам** выгружал определения через ~25, ~85 и ~145 секунд после запуска —
это подвешивало игру примерно на 10 секунд (сканирование всех объектов игры рефлексией).
Теперь автовыгрузка **выключена по умолчанию**. Включить при необходимости —
в `<игра>\BepInEx\config\com.noms.localizationpatch.cfg`, параметр `AutoDump = true`.
Обычная выгрузка — вручную: `Ctrl+F4` и `Ctrl+F6`.

## Отладочный вывод (изменено в 3.3.1)
Игроку в логе достаются только строки о загрузке перевода. Остальное выключено по умолчанию
и включается флагами в `<игра>\BepInEx\config\com.noms.localizationpatch.cfg`:

| Параметр | По умолчанию | Что включает |
|---|---|---|
| `ShowDebugWindow` | `false` | окно статистики по `F9`/`F10` |
| `VerboseLog` | `false` | `[TRACE] hit/miss`, пульс `[HB]` раз в 10 с, выгрузка `untranslated.txt` раз в 60 с |
| `AutoDump` | `false` | авто-выгрузка определений при запуске (подвешивает игру) |

Для доработки перевода: `VerboseLog = true` (+ при необходимости `ShowDebugWindow = true`).

## Правила перевода
- Названия оружия, техники, миссий и ливрей остаются на английском.
- Описания, подсказки и интерфейс — переводятся на русский.
- Деньги, дистанции, таймеры, координаты сетки не переводятся.

## Журнал правок словаря
- Раунд 11: добавлены trim-версии ключей (149 записей) — плагин сравнивает текст
  после `Trim()`, поэтому ключи с крайними пробелами не срабатывали.
- Раунд 12: брифинги/туториал, описания миссий, статусы HUD (`<b>`), предупреждения
  и списки дорожной карты (67 записей).
- Раунд 13: подписи задач для шаблона «подпись + число/единица» (14 записей) +
  шаблоны в плагине (см. ниже).
- Раунд 14: полный разбор ресурсов игры (`NuclearOption_Data\resources.assets`,
  `level0…level5`) — все брифинги в чате (`Message`/`message`), описания миссий и
  уроков (`description`), подсказки обучения (`body`, `title`) (225 записей).
  Исправлены неточности: `Flares rearmed by` → «Ловушки пополнены»,
  `Popping Flares` → «Отстрел ловушек».
- Раунд 15: разбор 15 миссий Ironjaw Sound из `AppData\LocalLow\Shockfront\NuclearOption\Missions\`,
  описания FS-41/KAR/Carrier Duel Lite и имена целей/точек маршрута из `resources.assets`
  (`objectives[].DisplayName`). Источник жалобы: `Ingress Via Mountains` → «Вход в район через горы»
  (223 записи). Затем имена целей/точек базовых миссий: `Destroy Radar` → «Уничтожить РЛС»,
  `Sink Enemy Carrier` → «Потопить авианосец противника», `Defend Maris Airport` и др.
  (55 записей). Названия техники/локаций в именах целей оставлены английскими
  (`Maris Airport`, `Island5 Airstrip`, `Boscali`).
- Возврат названий на английский: `Radome`, `Ammo box`/`Ammo Box`, `Cursor Class LFD`,
  `Argus Class Frigate`, `4xS1 Turret`, `MSV LADS`, `MSV MRAP` (7 записей удалено).

## Шаблоны в плагине (v3.3.0)
- `подпись + число/единица` (например `Return To Base 7,5km` → `Возврат на базу 7,5km`).
  Переводится только если подпись входит в белый список `LabelWithValueKeys` и есть
  в `ru.json`; иначе строка остаётся как была (HUD `RNG`, `ALT`, имена техники и т. п.).
  Поддерживаются номера: `Taxi to Runway 01 461m` → `Руление к ВПП 01 461m`.
- Диалог завершения игры: `Are you sure you want to end the game? Doing so will kick N
  other players.` → `Вы уверены, что хотите завершить игру? Это исключит из игры N игрока(ов).`
  (число и падеж подставляются автоматически).

## Известные ограничения
- Названия техники/миссий/локаций в составе «подпись + число» не переводятся
  (`Dustbowl Highway Strip 5,7km`, `AFV8 APC +2,3`) — по правилам они остаются английскими.
- Значения на HUD (`RNG 1,0km`, `ALT 1000m`, `V -1,9`) не переводятся.

## Файлы выгрузки (для разработки перевода)
- `untranslated.txt` — строки, которые игра показала, но перевода нет (пишется раз в 60 с
  при `VerboseLog = true`).
  Деньги, дистанции/массы, таймеры, координаты сетки и единицы измерения туда не попадают —
  они отсеиваются фильтром `IsJunkForTranslation` (переводить их не нужно).
- `extracted_gamedata.txt` — подсказки и энциклопедия (`Ctrl+F4`)
- `extracted_strings.txt` — все длинные строки из загруженных объектов (`Ctrl+F6`)
- Брифинги/описания/подсказки можно достать и напрямую из ресурсов игры
  (`resources.assets`, `levelN`): поля JSON `Message`, `message`, `description`,
  `body`, `title`. Скрипты разбора: `C:\Users\user\Documents\NuclearOption_Rus\tools\`
  (`mission_fields.py`, `prep_mission.py`, `merge_mission.py`, `merge15b.py`).

## Бэкапы словаря (важно)
Файлы `ru.json` и выгрузки легко потерять (случайное удаление, чистка менеджером модов).
Копии словаря лежат вне папки плагина:
- `C:\Users\user\Documents\NuclearOption_Rus\dict\ru.json` (репозиторий проекта)
- `<игра>\BepInEx\config\LocalizationPatch\ru.json`
